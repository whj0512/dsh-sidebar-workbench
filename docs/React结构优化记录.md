# React 结构优化记录

日期：2026-10-28。范围：插件 React 组件结构，依据 vercel-react-best-practices 的组件 memo、派生状态与 effect 依赖建议。未推进 T00–T05 后续阶段。

## 变更

- 从 Workbench 提取导航、项目、流程入口、模型预览、运行卡片及运行相关视图；材料表单增加 memo。展示组件接收所需 props，不自行建立宿主订阅。
- 菜单开关状态归属 WorkbenchChrome；导航、模型选择、启动和材料初始化使用稳定回调。材料字段单独派生，避免整个视图对象使表单缓存失效。
- 草稿保护 effect 依赖草稿是否为空；模型预览不随草稿逐字输入重新渲染。语言翻译函数变化仍会刷新展示组件。
- 产物展平和待授权运行查找移入对应页面；最新运行查找从后向前扫描，不复制或反转原数组。
- 保留既有 CSS、typed locale、公开 UI primitives 导入、Slot 注入、状态字段及运行命令。没有修改宿主源码或已有项目文件。
