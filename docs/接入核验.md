# 宿主接入核验（T00）

核验日期：2026-10-26。插件与相邻 Host 均以 DSH 0.2.1-rc.3 为兼容目标。目标目录不是 Git checkout；修改只发生在插件目录。

| 能力 | 公开入口与核验结论 |
|---|---|
| 原生页面 | `packages/client/ui-sidebar-right/src/client/contract/slots.ts` 的 `sidebar.right.pane.tab` 为 Session scope，提供 `useTabInfo`，包括 pane、tab 和 occurrence signal；不能把 signal 当作任务寿命 |
| 视图状态 | `dsh-client-store` 的 `defineStore`，在 apply 内创建 handle，作为 Slot store 声明；按 tab 与工作区键隔离草稿 |
| 工作区归属 | `dsh-api-workspace-controller/client` 的 `workspaces.list` 提供 phase/state/items，各行包含 workspaceId/path/title/sessionIds；pending 与无成员分别处理 |
| Host 工作区 | `dsh-workspace` 的 `workspaceRegistry.get/list` 与 Workspace.path、sessionIds；不使用进程 cwd 或路径前缀推断成员 |
| 执行 Session | `packages/api/session-controller/src/commands.ts` 接受 workspaceId；业务执行器未接入，不创建假执行会话 |
| 文件预览 | `ui-sidebar-documentpreview` 经资源地址和 `workspaceFiles` Remote 读取文件；业务文件须先经插件资源验证，不把 demo 标签作为真实路径打开 |
| Remote | `TypertRemoteService` / `@Remote`、`./typert` Host 描述与 `./remote` Client contribution；严格参数校验与 resource authorization 属于 Gateway |
| 存储 | `dsh-storage-domain` 的 schema/version、global/table 及 durability-first 写入；业务域不能放在 localStorage |
| 任务 | 宿主 jobs/subagent 属于实际执行所有者，不能将页面定时器作为调度器；本插件先以显式推进的 demo adapter 验证状态规则 |
| 业务能力 | 手册中的 QwenPaw 角色没有在本插件安装或注册；全部生产执行保持不可用 |

S01/S02 对应 P02 条目与差异审核；S03 对应 P03/P04；S04/S05 对应 P04/P05；S06 对应 P06；S07–S10 对应 P07/P08。所有业务场景证据须标注 demo，不能冒充模型验证。
